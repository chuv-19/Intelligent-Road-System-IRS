##  Архитектура и функциональные возможности

Система состоит из программной части (десктопное приложение на Python) и аппаратного модуля управления на базе микроконтроллера Arduino.

### 1. Визуальный редактор карт (PyQt6)
* **Интерактивное графическое поле (Grid):** Сетка размером $21 \times 21$ ячейка с поддержкой динамического отслеживания координат курсора (координаты отображаются во всплывающих подсказках ToolTip).
* **Многослойная компоновка:** Раздельное размещение элементов дорожного полотна (дороги, перекрестки) и статических/динамических объектов (машины, пешеходы, дорожные знаки, зебры, светофоры).
* **Контекстное управление:** Возможность поворота объектов на угол, кратный $90^\circ$, циклическая смена состояний/типов объектов (например, переключение маркировки знаков или цвета машин) и удаление элементов.
* **Сериализация (JSON):** Полное сохранение конфигурации карты в файл `map.json` и возможность экспорта/импорта схем через диалоговые окна Windows.

### 2. Подсистема автоматизации и управления светофором
* **Ручной режим:** Прямое управление сигналами светофора из графического интерфейса с мгновенной отправкой управляющих байт-кодов на аппаратный макет.
* **Автоматический режим:** Работа по аппаратному таймеру с циклическим переключением фаз (Красный $\rightarrow$ Желтый $\rightarrow$ Зеленый) с интервалом в 3 секунды.
* **Синхронизация через Serial (UART):** Передача данных по последовательному интерфейсу на скорости 9600 бод. Внедрена отказоустойчивость: при отсутствии физического подключения к COM-порту система изолирует ошибки и продолжает работу в режиме симуляции.

### 3. Журналирование событий (SQLite)
* Локальное хранение истории работы системы в файле `events.db`.
* Автоматическая фиксация событий в таблицу `events` с занесением точной временной метки (`YYYY-MM-DD HH:MM:SS`) и описания операции (переключение режимов, смена сигналов, команды пользователя).

### 4. Модуль микроконтроллера (Arduino C++)
* Считывание входящих команд по протоколу UART (`'R'` — красный, `'Y'` — желтый, `'G'` — зеленый).
* Реализация аварийного режима работы (мигающий желтый сигнал) по триггерам `'B'` (включить) и `'K'` (выключить).
